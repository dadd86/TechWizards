# Paquete `com.diegodiaz.techwizards.integration`

Contiene integraciones con servicios del dispositivo o módulos externos (multimedia, celebraciones). Actualmente incluye stubs que servirán como puntos de extensión.

## Subpaquetes

| Subpaquete | Propósito |
| --- | --- |
| `media` | Control de reproducción musical in-app. |
| `victory` | Servicios relacionados con celebraciones de victoria (animaciones, geolocalización, compartición). |

Cada subpaquete expone clases simples que deberán completarse con lógica real al conectar SDKs externos.
